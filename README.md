# Advanced Topics in Cryptography — Assignment 1

## Zero-Knowledge Proof: Sudoku

This project is a React application for the Sudoku zero-knowledge-proof assignment. The intended demonstration is that a **prover** can convince a **verifier** that they know a valid Sudoku solution without revealing the solution itself.
